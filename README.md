## 📌 Sobre o Projeto

O **Inkwell** é uma aplicação web completa desenvolvida com arquitetura desacoplada, utilizando **React** para uma interface fluida e moderna no frontend, e **PHP com MySQL** no backend para gerenciamento seguro de dados e autenticação.

Projetado para oferecer alta performance e uma experiência de usuário simplificada, o sistema conta com integração contínua e deploy automatizado na **Vercel** e no **Railway**.

---

## ✨ Funcionalidades Principais

- 🔐 **Autenticação Segura**: Fluxo completo de login, registro e controle de sessões.
- ⚡ **Dashboard Dinâmico**: Painel interativo para gerenciamento em tempo real.
- 🔍 **Módulo de Busca**: Pesquisa otimizada e filtragem rápida de elementos.
- 🎨 **Interface Responsiva**: Design moderno, adaptado para desktops, tablets e dispositivos móveis.
- 🚀 **Alta Disponibilidade**: Backend escalável hospedado em nuvem.

---

## 🛠️ Tecnologias Utilizadas

### **Frontend**
- **React.js** (Componentização e Gerenciamento de Estado)
- **Vercel** (Hospedagem e Continuous Deployment)
- **CSS3 / Tailwind** (Estilização e Layout Responsivo)

### **Backend & Banco de Dados**
- **PHP** (API RESTFUL e Regras de Negócio)
- **MySQL** (Banco de Dados Relacional)
- **Railway** (Infraestrutura de Servidor e Cloud Database)
